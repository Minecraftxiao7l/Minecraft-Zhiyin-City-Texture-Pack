# Minecraft-Zhiyin-City-Texture-Pack
This is the Zhiyin City texture pack for Minecraft. It supports versions 1.21.9x+ on the International Bedrock Edition! And versions 1.20+ on the Java Edition!

## Installation

### Bedrock Edition (International)
1. Download the .mcpack file.
2. Open the .mcpack file and choose "Minecraft" when prompted to import the pack.
3. Launch Minecraft and go to Settings.
4. Under Settings, open "Global Resources", then go to "My Packs".
5. Find the pack you just imported, click it, and select "Activate".
6. Press the back button to return to the game — the texture pack should now be active.

### Java Edition
1. Download both .zip files.
2. Move the downloaded .zip files into Minecraft's `resourcepacks` folder:
   - On Windows: `%appdata%\\.minecraft\\resourcepacks`
   - On macOS: `~/Library/Application Support/minecraft/resourcepacks`
   - On Linux: `~/.minecraft/resourcepacks`
3. Start Minecraft, go to Options → Resource Packs.
4. In the Resource Packs screen, move the new packs from the left column to the right (active) column.
5. Click Done to apply the packs.

Notes:
- Make sure you use the version of the game listed in this repository for best compatibility.
- If a pack does not appear after importing, try restarting Minecraft or checking that the file extension is `.mcpack` (Bedrock) or `.zip` (Java).

### Android (Mobile Launcher)

Note: Minecraft Java Edition does not have an official Android client. The two options below cover the usual ways people install texture/resource packs on Android devices.

A. Official Bedrock / Pocket Edition (recommended)
1. Download the .mcpack file to your Android device.
2. Open a file manager and tap the downloaded .mcpack file.
3. When prompted, choose "Minecraft" to import the pack.
4. Launch Minecraft, open Settings → Global Resources → My Packs.
5. Find the pack you imported, select it, and tap "Activate".
6. Press Back to return to the game — the pack should now be active.

B. Using a third‑party Android launcher or addon manager (optional, compatibility varies)
1. Install a trusted third‑party Minecraft launcher/addon manager that supports resource packs on Android (examples exist for older Minecraft versions; availability varies by region and Android version).
2. Download the resource pack .zip file(s) to your device.
3. Follow the launcher/app instructions to add or import resource packs. Typically this involves placing the .zip in a specific folder (often named `resourcepacks`, `addons`, or similar) or using the app's Import/Add feature.
4. In the launcher/app, enable the resource pack for the world or profile you will run.
5. Start Minecraft through the launcher/app and confirm the textures are applied.

Caveats:
- Many third‑party launchers are out of date or only support older Minecraft versions — packs may not work on the latest game release.
- Third‑party apps may request permissions and can pose security risks; only use well‑known, reputable apps and consider scanning downloads for malware.
- If the pack doesn't work on Android, convert or obtain a Bedrock-compatible `.mcpack` version where possible — Bedrock `.mcpack` is the most reliable format for mobile devices.
